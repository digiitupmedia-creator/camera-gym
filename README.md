# Camera Confidence Gym — AI Coach V1

A deployable upgrade of the existing personalised arcade gym. Keeps the 30-day communication wheel, browser recording, manual self-review, one-correction repetition and local session history.

## What AI does

- With explicit consent, sends the **current take only** to Google's Gemini API through a Vercel backend.
- Returns communication ratings (1–4), concrete timestamp/quote evidence where supported, **one correction**, and one practice drill.
- On take two, provides a **qualified comparison against the first take's AI analysis summary**. The first video is **not** re-uploaded; this is *not* direct two-video comparison. If the first take was not analysed, the coach explains that no fair comparison is available.
- AI is optional. Manual review works even without an API key.

## Deploy on Vercel

1. Unzip this folder. Import it as a new Vercel project (via GitHub or Vercel CLI). Root directory is `camera-gym-ai-v1` if importing a parent repository.
2. Set project environment variable **`GEMINI_API_KEY`** to your own key from Google AI Studio. Never paste the key into HTML or a public Git repository.
3. Set optional **`GEMINI_MODEL`** (default: `gemini-2.5-flash`). Confirm the model is enabled for your key.
4. Framework preset: **Other**; no build command needed. Deploy. Open the resulting HTTPS URL.
5. Allow camera and microphone permissions. Record a first take, tick the AI consent checkbox, tap **Analyse first take**, select one manual correction, and record your second take. Tick consent again and tap **Analyse corrected take & compare**.

## Test locally

Node.js 20+: `GEMINI_API_KEY=your_key node dev-server.js`, then open `http://localhost:3000`. `localhost` is generally considered a secure context for camera permissions. Do not put API keys in source code.

## Privacy and limitations

- Recordings are held in browser memory and are **not** stored in history or on the backend. Video contents are temporarily transmitted to Google's API upon consent and may be processed/retained under Google's terms. Review Google API privacy/data handling terms before using client-sensitive footage.
- No patient information, confidential names, case files or private client data should appear in the recording.
- Manual training session notes and limited AI dimension/correction summaries are saved to localStorage. Video files are never saved automatically. The user can download a take during review.
- HTTPS or localhost required for camera access; opening an HTML file via Android `content://` will not reliably work.
- Short recordings recommended (45–75 seconds). Approx **2.6 MB video limit** for this deployment. The recorder requests reduced bitrate, but actual recording size is browser-dependent.
- No server-side authentication or per-user rate limit is included. For private personal deployment, enable Vercel Deployment Protection or add authentication before sharing the URL, to prevent third parties spending your API quota.
- JSON analysis is generated by AI and may be incorrect. Timestamps, quotes and scores should be checked against the recording; no facial attractiveness/emotion/personality metrics are produced.
- The second-take comparison is *summary-based*, not a direct side-by-side analysis of both videos. That more rigorous comparison is a future upgrade if required.

## Files

- `index.html`: full front-end, wheel, recording, review, Gemini coaching UI
- `api/analyze.js`: private Gemini API proxy with input checks and no-store response
- `vercel.json`: deployment and security headers
- `dev-server.js`: optional minimal localhost development server
- `.env.example`: list of server-side environment variables
